Detailed Description

Represents a quaternion for 3D rotations.

Quaternions provide a more robust and efficient way to represent rotations compared to Euler angles, avoiding issues like gimbal lock.

This class provides functionalities for creating, manipulating, and using quaternions for various 3D rotation operations.
