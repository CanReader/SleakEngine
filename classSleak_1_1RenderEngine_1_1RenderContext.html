Detailed Description

Abstract interface for high-level graphics command execution and resource management.

  • The RenderContext acts as the primary bridge between the Sleak Engine's logic and the underlying Graphics API (Vulkan, DX11, etc.). It provides a unified set of commands for:
  • Command Dispatch: Executing non-indexed, indexed, and instanced draw calls.
  • State Management: Configuring the pipeline state (Viewports, Culling, Rasterization).
  • Resource Creation: Serving as a Factory for API-specific buffers, shaders, and textures.
  • Resource Binding: Mapping hardware buffers to specific pipeline slots.
  • Note
    This is a pure virtual interface. Implementations (e.g., VulkanRenderContext) must handle the specific synchronization and driver-level requirements of their respective APIs.
